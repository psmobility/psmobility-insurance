PSMOBILITY 모바일 보험관리 PWA v2.1 — 설치 안내

1. ZIP을 압축 해제하고 index.html, manifest.webmanifest, sw.js, icons/ 폴더를 모두 함께 HTTPS 정적 호스팅에 올립니다.
   예: GitHub Pages 또는 Cloudflare Pages의 독립적인 비공개 업무용 배포 경로.
   _headers 파일은 Cloudflare Pages 같은 지원 호스팅에서 보안 응답 헤더 설정에 사용됩니다.
2. 안드로이드 Chrome으로 HTTPS 주소의 index.html에 접속합니다. 메뉴(⋮) → '앱 설치' 또는 '홈 화면에 추가'를 누릅니다.
3. 홈 화면 아이콘 '평생 보험관리'를 실행하고 기존 Supabase 이메일/비밀번호로 로그인합니다.
4. 고객 목록과 독립계약 A1/A2 상세를 PC와 대조합니다. 조회 전용이며 PC 편집 권한을 획득하지 않습니다.

주의:
- HTML을 파일 관리자에서 file://로 직접 열거나 ZIP만 휴대폰에 내려받으면 PWA 앱 설치가 되지 않습니다. 반드시 HTTPS 배포가 필요합니다.
- 고객과 계약 서버 응답은 로컬 캐시에 보관하지 않습니다. 앱 셸(로그인 화면 코드/아이콘)만 서비스워커에 캐시됩니다.
- 기존 모바일 v2.0과 같이 '자동 로그인 유지'를 체크하면 리프레시 토큰이 기기의 localStorage에 저장될 수 있습니다. 공용 기기는 체크를 해제하세요.
- 로그인 및 고객 정보 열람에는 인터넷 연결이 필요합니다. 서버 연결 실패 시 고객 정보는 화면에서 제거합니다.
- 정적 파일 공개 URL을 안다고 로그인 없이 고객 데이터를 열람할 수는 없지만, 이 URL의 존재 자체를 접근 통제로 간주하지 마세요. 서버 RLS 정책 및 계정 관리가 필수입니다.
- 배포 계정과 URL은 제공되지 않았으므로 외부 배포는 완료하지 않았습니다.
- 앱 출시 전 실제 모바일 장치, PC 동시 로그인, 세션 만료, 서버 장애 시나리오를 테스트해야 합니다.
